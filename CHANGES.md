## Phase 0 — dev loop + plumbing
- `src/bin/rcon.rs` + `[[bin]] rcon` in Cargo.toml: RCON CLI over the crate's own client (env RCON_HOST/PORT/PASS, default Server B tunnel 25576). No ssh, no mcrcon.
- `scripts/probe.sh X Y Z …`: ground-truth block name via `execute if block` candidate sweep; forceloads the chunk for the probe.
- `scripts/snapshot.sh <bot>`: clone the 21×11×21 region around a bot's last race.db position into a reserved slot (x=1500+64·slot, z=1500, same Y) + write `snapshots/<bot>-<ts>.env` (corners, bot offset, translated frame anchor, inventory).
- `scripts/gym-from-snapshot.sh <env> [step] [secs] ["item n"…]`: kit + tp a `rust-snap-NNN` bot into the slot with the recorded inventory/anchor and run one step in STEVE_TEST mode on Server B.
- `scripts/rate-report.sh [db]`: per-bot furthest/current step, minutes-in-step, deaths, bails, wins; minutes-to-milestone; enter_nether success rate + median/p90; median minutes per step; deaths by place; top failures; crafting-flake count.
- `race-b.sh`: a goal reached is recorded and announced, never a stop — race runs the full RACE_SECONDS and ends by printing the rate report.
- `src/app.rs`: RACE_GOAL reached → record win once and KEEP RUNNING (RACE_STOP_ON_GOAL=1 restores the old exit); drain the cast's internal death counter into race.db death events after each step.
- `src/tasks/portal.rs`: `CAST_DEATHS` counter + `take_cast_deaths()` (respawn_at_frame deaths were invisible to race.db).
- `src/steps.rs`: `preconditions_ok(step_id, state)` — tools a step must HOLD (pickaxe for mining/portal steps, buckets+flint&steel for the portal); `get_next_step` drops back to the earliest runnable incomplete step when the furthest step's preconditions fail (the pick=None-in-build_nether_portal spin).
