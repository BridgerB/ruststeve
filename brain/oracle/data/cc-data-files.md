# clojurecraft's data files

## Generated by `bb datagen` (regenerate for ruststeve)

| File | Holds |
|---|---|
| `version.edn` | 26.1.2, Java 25, protocol 775, world version 4790 |
| `packets.edn` | packet ids by state and direction ([[wire-packet-ids]]) |
| `blocks.edn`, `block-states.edn`, `items.edn`, `entity-types.edn` | registries |
| `hardness.edn`, `harvest.edn`, `materials.edn`, `needs-tool.edn` | dig speed and drops ([[mc-dig-timing]]) |
| `recipes.edn`, `item-tags.edn`, `smelting.edn`, `fuel.edn`, `drops.edn` | crafting, smelting, fuel, loot ([[mc-recipes]]) |
| `components.edn` | data component ids ([[wire-slots]]) |
| `dimensions.edn`, `biomes.edn`, `biome-spawns.edn` | dimension heights, biomes, spawn lists |
| `damage-types.edn`, `attributes.edn`, `mob-effects.edn`, `sounds.edn`, `menus.edn` | registries a fight and a window are told in |

## Hand-written (port as data, with their comments)

| File | Holds |
|---|---|
| `goals.edn` | the goal table ([[cc-goals-and-intents]]) |
| `problems.edn` | a problem statement per stage ([[cc-roadmap-stages]]) |
| `pearls-rules.edn`, `pearls.edn`, `pearls-history.edn` | the pearl hunt's rules, thresholds and incident history ([[cc-pearls-rule-table]]) |
| `threats.edn` | per-kind threat facts and the cover ladder |
| `junk.edn` | what a full inventory throws, and what it keeps (building blocks, food) |
| `mob-kinds.edn`, `mobs.edn` | mob numbers for the server model |
| `shapes.edn` | block collision shapes |
| `starts.edn`, `gyms.edn` | race starts and the gym registry ([[cc-race-and-gym]]) |

## For ruststeve
Every number in the hand-written files is a `Config` field or a data table, never a literal in code ([[accents]]). Their comments carry the evidence for each value; keep them with the data.
