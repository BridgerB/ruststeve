# Harness

How clojurecraft is tested, measured and fed.

- [[cc-record-replay]] - events and effects as EDN lines; `verify` on sent packets.
- [[cc-sim]] - the pure server model, captured worlds, the sim race, snapshots judged on base and fix.
- [[cc-test-suite]] - tests, properties, static checks, workflows.
- [[cc-datagen]] - game tables generated from the server jar.
- [[cc-observability]] - case files, ledger, senses, truth and the coverage row: what every ended run leaves.
- [[cc-race-and-gym]] - gyms judged by RCON truth reads; races on paired landing sets.
- [[cc-roadmap-stages]] - every stage's last recorded failure; where clojurecraft stands.
