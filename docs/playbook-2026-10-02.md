## Rules learned in cycle 2 (apply this cycle)

- A build is measured by **two full gym batches** before the next change, except for a safety bug.
- Any change to `leave_water` or a timing primitive runs the **full water regression** before it ships.
- Gym experiments run on `target-gym` (`BIN=…`). A live race's `target/` is never rebuilt with code meant for the gym.
- No `spreadplayers` in fresh regions: surface placement waits for the async forceload.
