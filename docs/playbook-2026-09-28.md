## Phase 0 — dev loop and plumbing (hours 0–3)

- `scripts/snapshot.sh <bot> [radius]` — bot position from race.db → region dump (default 20×10×10) as setblock list into `snapshots/<bot>-<ts>.mcfunction` (or RCON `clone` into a reserved gym area if faster/reliable).

- `scripts/rate-report.sh [race-id]` — per bot: time spawn→each step, deaths (count + step), time in current step; aggregate: enter_nether success rate, median/p90 time-to-enter_nether, median time per step. Every race/gym batch ends with it.

Structural fixes:
1. **Step preconditions** — required-inventory predicate per step; selection drops back to the earliest step whose preconditions fail. Test: delete a pickaxe from a gym bot mid-step → it goes back to craft one.
2. **Race driver win condition** — "winner" = last implemented step, not enter_nether; do NOT kill other bots when one wins.
3. **Spawn in water** — preamble to step 1: if in water, swim to nearest non-water column. Test by tp into ocean.
4. **Pour position assertion** — pour only when feet == intended stand block exactly and on ground; else re-walk. Never pour from a wrong position.

## Phase 1 — template mold on a prepared pad (hours 3–14)
- **Where:** after fill_bucket front-loads lava, do NOT cast at the sea edge. Find/make a flat 6×4 area 3–4 blocks back from the pool edge with a one-block cobble rim between pad and lava (~40 blocks; the bot carries hundreds of cobble). Standing distance from lava kills; refill distance only costs seconds.
- **What:** constant template of offsets from a pad origin (back wall, front wall, side walls, corners, cobble fill of the 2×3 interior). Every template block is placed; nothing in the template is ever dug.
- **Order:** layer by layer, bottom-up. Per layer: place that layer's template blocks; from the fixed stand position pour lava from above into each frame cell (enclosed 4 sides + below → no flow); pour water from above onto each lava source; scoop water back (one bucket serves the cast); verify each expected obsidian reads as obsidian before the next layer. Refills at a fixed pool station.
- **After:** dig the six interior cobble (the only digging), light, enter. Then DELETE the per-cell cup/bowl/pillar logic, the side-cast use, the "if block above is solid dig it" family, every neighbour-debris special case. Keep bottom-up ordering, blocks_never_break, aim-pour, protocol-775 facts.
- **Validation:** GYM=portal random real terrain, 10 runs before any race. Pass = 10 obsidian verified, zero deaths, cast <5 min from arrival at the pool. Every failure → snapshot → gym repro, never a race relaunch.
- **Timebox:** hour 9 check — is a layer-by-layer cast passing in the gym at all? If not, simplify (more cobble, longer walks) rather than add cases. Hour 14 — if <8/10, take best variant, record rate, move on.
